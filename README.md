# table_desc_to_ddl
:테이블 정의서을 읽어 DDL을 만들어주는 프로그램. 산출물만 존재하는 이전 솔루션의 DB를 복원하고자 개발.

# Specification
<ul>
  <li>java8</li>
</ul>

# Description
##### 사용방법
<ol>
	<li>프로젝트 경로 내 csv 파일 위치 (엑셀 다른이름으로 CSV utf-8 파일 저장)</li>
	<li>main메서드 실행</li>
	<li>console 창에 출력되는 테이블 생성 DDL 확인</li>
	<li></li>
</ol>
